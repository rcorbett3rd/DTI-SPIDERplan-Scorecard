# Upload Instructions — Flat Repository

This package intentionally contains no required folders.

1. Extract the ZIP.
2. Upload every file inside the extracted folder to the root of one GitHub repository.
3. Do not rename any file.
4. In Streamlit Community Cloud use:
   - Branch: main
   - Main file path: app.py
5. In Streamlit advanced settings, select Python 3.11 if available.

`streamlit_config.toml` is only a backup of the optional theme configuration.
The app does not depend on it for startup.
